# Photos

Put site photos here, one folder per event or section:

```
src/assets/photos/
  home/hero.jpg            ← home page hero (any of .jpg .png .webp)
  fall-2026/ode-info-1.jpg ← event photos, listed in the events tab "photos" column
  board/president.jpg      ← headshots, listed in the board tab "photo" column
  alumni/jane-doe.jpg      ← alumni headshots
```

In the sheet, write the path **after** `photos/`, e.g. `fall-2026/ode-info-1.jpg`.

Before adding a photo:

- Resize it to **at most 2000 px on the long edge**. The site makes smaller versions automatically.
- Only use photos of people who've agreed to be photographed and posted.
- Write real alt text that describes the scene (events tab `photo_alts` column), e.g.
  "Students at the October ODE information session". Never "image" or a filename.
